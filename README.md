✈️ AI-Powered Flight Booking Assistant

📌 Project Overview

This project is an enterprise-grade, conversational AI flight booking agent. It allows users to search for flights, get nearest airport recommendations, check weather forecasts, predict flight delays using Machine Learning, and complete mock payments—all through a natural language interface.

This is my final year M.Tech project, demonstrating a complete full-stack AI and software engineering lifecycle.

🛠️ Technology Stack

Frontend: Streamlit

Backend: FastAPI

AI Framework: LangChain

LLM: Gemini / OpenAI

Database: MySQL

Machine Learning: Scikit-learn (Random Forest / XGBoost)

Version Control: Git & GitHub

Payment Integration: Razorpay (Test Mode)

✨ Core Features

[x] Conversational AI: Multi-turn chat interface capable of understanding complex travel requests.

[ ] Live Flight Search: Real-time data aggregation using Serper/Amadeus APIs.

[ ] Smart Recommendations: Nearest airport detection based on user input.

[ ] Weather Integration: Destination weather forecasting.

[ ] Delay Prediction ML Model: Historical data-driven probability of flight delays.

[ ] End-to-End Booking: Human-in-the-loop approval and mock payment gateway.

[ ] State Management: User authentication, booking history, and MySQL chat logging.

🏗️ Architecture Flow

User Interaction: The user interacts with the Streamlit frontend.

API Routing: Requests are routed asynchronously through FastAPI.

Agentic Workflow: LangChain interprets the intent and triggers specific tools (Serper API, Weather API, ML Model).

Data Persistence: User sessions, chat history, and mock bookings are stored securely in MySQL.
